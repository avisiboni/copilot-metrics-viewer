# תרומה לפרויקט

1. Fork + branch
2. `npm install` + `npm test`
3. Pull request עם תיאור ברור

ראו `CONTRIBUTING.md` בשורש המאגר.

שינוי בקוד שמשפיע על משתמשים — עדכנו **עברית** (`website/docs/`) ו-**אנגלית** (`website/i18n/en/...`).
