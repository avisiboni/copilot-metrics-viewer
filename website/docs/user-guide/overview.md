# מדריך למשתמש

מדריך זה מסביר איך להשתמש בלוח הבקרה **ללא** הגדרות שרת.

![צילום מסך של לוח הבקרה - Overview](/img/ui/dashboard-overview.png)

## זרימת עבודה מומלצת

1. בחרו **טווח תאריכים** (עד 100 יום) — [ניווט ותאריכים](./navigation-and-dates).
2. עברו ללשונית הרלוונטית (ארגון, משתמשים, חיוב וכו').
3. סננו לפי משתמש / צוות / יום לפי הצורך.
4. ייצאו דוחות מ-**API response** אם נדרש CSV (מדדי Copilot בלבד — ללא PRU).
5. לפירוט כל KPI, עמודה ורכיב — [מדריך רכיבי UI](./ui-reference/overview).
