# כתובות URL לפי צוות

ניתן לפתוח את הלוח **מסונן מראש לצוות אחד** — כל הלשוניות (שפות, עורכים, צ'אט, משתמשים וכו') מציגות רק חברי הצוות.

## תבניות URL

```
https://<host>/orgs/<org>/teams/<team>
https://<host>/enterprises/<enterprise>/teams/<team>
```

דוגמאות מקומיות:

```
http://localhost:3000/orgs/octo-demo-org/teams/the-a-team
http://localhost:3000/orgs/mocked-org/teams/the-a-team?mock=true
```

## ממשק

- **באנר כחול** בראש הדף — שם הצוות וקישור **חזרה לארגון**.
- מסנן התאריכים הגלובלי חל על כל הלשוניות.

## איך זה עובד

GitHub לא מספק endpoint ייעודי למדדי צוות. האפליקציה:

1. מורידה מדדים **לפי משתמש** (ארגון/Enterprise).
2. פותרת חברות בצוות דרך **Teams API**.
3. מסננת ומצרפת בזיכרון.

זה עובד ב-**Direct API** (חלון 28 יום) וב-**Historical mode** (היסטוריה מלאה).

## לעומת לשונית Teams

| | **URL לפי צוות** | **לשונית Teams** |
|---|------------------|------------------|
| מטרה | דשבורד מלא לצוות אחד | השוואה בין צוותים |
| בחירה | מה-URL | רשימת צוותים בלוח |

ראו [צוותים](./teams).
