# לשונית Users

טבלת **שימוש לפי משתמש** מהדוח users-28-day (או users-1-day ליום בודד).

:::info מדריך מפורט
[לשונית Users (מלא)](./ui-reference/users-tab) · [עמודות הטבלה](./ui-reference/users-table-columns) · [Premium credits / בקרוב](./ui-reference/premium-credits)
:::

![צילום מסך של לשונית Users](/img/ui/users-tab.png)

## עמודות עיקריות

| עמודה | תיאור |
|-------|--------|
| User | לוגין GitHub (ואם זמין — שם / אימייל) |
| Premium credits | מכסת PRU — פס התקדמות כשה-API זמין |
| מודלים / תכונות | שימוש ב-Agent, Chat, CLI וכו' |

## בדיקת סטטוס חיוב

כרטיס **Billing status** + **Check now** בודקים את GitHub Billing Usage API לטווח הנוכחי.

## מסננים

- **Filter by day** — דוח יומי (השאירו ריק ל-28 יום גלגוליים).
- **Filter by user** — התמקדות במשתמש אחד.
- חיפוש בטבלה.

:::info
אם Premium credits מציג **N/A** — ראו [תקלות Billing API](../troubleshooting/billing-api).
:::
