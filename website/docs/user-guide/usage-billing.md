# לשונית Usage & billing

משלבת **דוחות שימוש Copilot** עם **נתוני חיוב** מ-GitHub (כשה-API זמין).

## KPI

- משתמשים פעילים, אינטראקציות, generations, acceptances
- כשהחיוב זמין: הוצאה נטו, PRU, מודלים בחיוב

## הודעת Billing API

אם החיוב לא נטען, מוצגת הודעה **מתקפלת** עם פרטי HTTP, scopes ונקודות קצה — לחצו לפתיחה.

## סינון משתמש

בחרו משתמש ב-**Filter by user** כדי לצמצם טבלאות וגרפים.

## גרפים

- מודלים מובילים
- אימוץ תכונות
- עלויות SKU / PRU לפי מודל (כשזמין)
