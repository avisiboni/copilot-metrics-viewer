# לשונית Usage insights

![לשונית Usage insights](/img/ui/usage-insights-tab.png)

תובנות על **מודלים**, תכונות Agent/Chat ושימוש ב-IDE.

## תכונות

- KPI לפי תקופה
- פאנלים מתקפלים לפי סוג מודל (השלמות קוד, צ'אט)
- גרפים לפי מודל ותכונה
- **קוהורטות AI adoption** — פאנל שלבי אימוץ (מוסתר כברירת מחדל; `NUXT_PUBLIC_SHOW_AI_ADOPTION_COHORTS=true`) — [תיעוד](../user-guide/ui-reference/ai-adoption-cohorts)

השתמשו בטווח התאריכים הגלובלי לסנכרון עם שאר הלשוניות.

**עמודות טבלאות המודלים:** [עמודות Usage insights](./ui-reference/usage-insights-table-columns).
