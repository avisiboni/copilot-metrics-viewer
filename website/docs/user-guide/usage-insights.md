# לשונית Usage insights

- גרפים לפי מודל ותכונה
- **קוהורטות AI adoption** — פאנל שלבי אימוץ (כשדוח 28 יום כולל `totals_by_ai_adoption_phase`) — [תיעוד](../user-guide/ui-reference/ai-adoption-cohorts)

השתמשו בטווח התאריכים הגלובלי לסנכרון עם שאר הלשוניות.
