# ייצוא נתונים (API response)

בלשונית **API response** ניתן:

| פעולה | תיאור |
|--------|--------|
| Download CSV (Summary) | דוח מקוצר |
| Download CSV (Full) | דוח מלא |
| Copy to clipboard | העתקה מהירה |
| Check data quality | בדיקת שלמות נתונים |

מתאים לדיווח ב-Excel או BI פנימי.
