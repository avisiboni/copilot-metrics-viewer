# לשונית Seat analysis

מנתחת **מושבי Copilot** — הקצאה, שימוש וחוסר פעילות.

![צילום מסך של לשונית Seat analysis](/img/ui/seat-analysis-tab.png)

## KPI

| מדד | משמעות |
|-----|--------|
| Total Assigned | מושבים מוקצים |
| Assigned But Never Used | הוקצו ולא נוצלו |
| No Activity (7 days) | ללא פעילות בשבוע האחרון |

## מושבים לפי חודש

מקטע **«מושבים לפי חודש»** מציג:

- **מצב היסטורי** (`ENABLE_HISTORICAL_MODE` + סנכרון יומי ל-PostgreSQL): סה״כ מושבים מוקצים **בסוף כל חודש** (מצילומי מצב יומיים).
- **ללא מצב היסטורי**: הקצאות חדשות לפי חודש לפי עמודת «זמן הקצאה» (רק מושבים שעדיין מוקצים).

אין מסנן חודש נפרד — הטבלה והתרשים מציגים את כל החודשים הזמינים בנתונים.

## טבלה

מציגה מושבים ללא פעילות, ממוינים לפי פעילות אחרונה.

:::info
לשונית זו **אינה** משתמשת במסנן התאריכים הגלובלי של שאר הלשוניות — מצב המושבים בטבלה הוא עדכני; מגמות חודשיות תלויות בצילומים היסטוריים או בתאריכי הקצאה.
:::
