# לשונית Seat analysis

מנתחת **מושבי Copilot** — הקצאה, שימוש, חוסר פעילות ומגמות חודשיות לחשבונית.

![צילום מסך של לשונית Seat analysis](/img/ui/seat-analysis-tab.png)

## KPI (כרטיסים לחיצים)

| מדד | משמעות |
|-----|--------|
| Total Assigned | מושבים מוקצים |
| Assigned But Never Used | הוקצו ולא נוצלו |
| No Activity (7 / 30 days) | ללא פעילות |

לחיצה על כרטיס מסננת את הטבלה התחתונה.

## מושבים לפי חודש

מקטע **«מושבים לפי חודש»** כולל:

- **תרשים עמודות מוערם** — מושבים חדשים + קיימים
- **טבלה** — פירוט לחשבונית (חודש, חדש, קיים, סה״כ)

### מקור נתונים

| מצב | חישוב |
|-----|--------|
| **Historical** (`ENABLE_HISTORICAL_MODE` + `NUXT_PUBLIC_ENABLE_HISTORICAL_MODE` + sync) | סה״כ מושבים **בסוף כל חודש** מצילומי מצב יומיים (`/api/seats-history`) |
| **Direct API** | הקצאות לפי חודש לפי `created_at` (מושבים שעדיין מוקצים) |

:::info
ללא מצב היסטורי — הודעה מסבירה איך להפעיל סנכרון לסה״כ חודשי מדויק.
:::

## הגדרות חיוב

כרטיס **Billing** (כש-API זמין): plan, IDE chat, platform chat, CLI, הצעות ציבוריות, ניהול מושבים.

## טבלת מושבים

רשימת מושבים — **ללא** מסנן תאריכים גלובלי (מצב עדכני).

**רשימת עמודות מלאה** (מושבים + טבלה חודשית): [עמודות Seat analysis](./ui-reference/seat-analysis-table-columns).
