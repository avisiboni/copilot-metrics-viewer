# לשונית Teams

![לשונית Teams](/img/ui/teams-tab.png)

מציגה מדדי Copilot **לצוות אחד** (deep dive) או **השוואה** בין מספר צוותים.

## איך המדדים מחושבים

GitHub **אינו** מספק API למדדי צוות ברמת endpoint ייעודי. האפליקציה:

1. מורידה מדדים **יומיים לפי משתמש** (ארגון/Enterprise).
2. פותרת חברות בצוותים דרך **GitHub Teams API**.
3. מסננת ומצרפת לפי צוות.

זה עובד ב-**Direct API** (עד 28 יום) וב-**Historical mode** (היסטוריה מלאה).

## שימוש

1. בחרו **צוות אחד** — KPI, גרפים (קבלה, משתמשים פעילים, מודלים, שפות, עורכים), טבלת משתמשים.
2. בחרו **שני צוותים ומעלה** — השוואה side-by-side.
3. השתמשו בטווח התאריכים הגלובלי.

## כתובת URL ישירה לצוות

לדשבורד מלא מסונן לצוות (כל הלשוניות):

```
/orgs/<org>/teams/<team>
```

[פרטים →](./team-scoped-views)

## מגבלת GitHub

לצוות חייבים להיות **לפחות 5 חברים עם רישיון Copilot פעיל** בסוף היום — אחרת הנתונים עלולים להיות ריקים.

## מצב היסטורי

ב-Historical mode ניתן לנתח מגמות צוות מעבר ל-28 יום. הגדרה: [מצב היסטורי](../deployment/historical-mode).

:::info
לשונית Teams מוצגת ב-scope **organization** ו-**enterprise**. היא לא מוסתרת במצב Direct API.
:::
