# לשונית Teams

משווה מדדי Copilot בין **צוותים** בארגון.

## שימוש

1. בחרו צוותים מהרשימה.
2. השוו KPI וגרפים בין הצוותים שנבחרו.
3. השתמשו בטווח התאריכים הגלובלי לעקביות.

:::warning
מדדי צוות זמינים רק כאשר לצוות היו **לפחות 5 חברים עם רישיון Copilot פעיל** בסוף היום (מגבלת GitHub).
:::
