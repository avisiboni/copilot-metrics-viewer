# לשונית Organization

מציגה מדדי Copilot ברמת הארגון / Enterprise לטווח שנבחר.

## כרטיסי KPI

| מדד | משמעות |
|-----|--------|
| Acceptance Rate (by count) | יחס קבלת הצעת קוד להצעות |
| Total Suggestions | סה"כ הצעות (פרומפטים) |
| Acceptance Rate (by lines) | קבלה לפי שורות |
| Total Lines Suggested | שורות שהוצעו |

## גרפים

- שיעור קבלה לאורך זמן
- ספירת הצעות מול קבלת הצעת קוד
- שורות שהוצעו מול התקבלו
- משתמשים פעילים
- DAU / WAU / MAU

:::tip
הסבר מפורט על כל מדד ב-[תיעוד GitHub Copilot Metrics API](https://docs.github.com/en/rest/copilot/copilot-metrics).
:::
