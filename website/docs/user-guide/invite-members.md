# לשונית Invite members

הזמנת משתמשי GitHub לארגון — **אימייל בודד** או **העלאת Excel מרוכזת**.

:::info
הלשונית מופיעה בסרגל הצד (`?tab=invite-members`). אין צורך בטווח תאריכים.
:::

## דרישות הרשאה

הטוקן (`NUXT_GITHUB_TOKEN` / OAuth) חייב להיות **בעלים של הארגון** עם:

- `admin:org` (classic PAT), או
- הרשאת Organization members: Write ב-GitHub App / fine-grained PAT

ראו גם [הרשאות GitHub](../reference/scopes).

## בחירת ארגון

| שדה | הסבר |
|-----|------|
| **Organization** | בורר ארגונים — הארגון הנוכחי מההגדרות, וארגוני ה-Enterprise (אם `NUXT_PUBLIC_GITHUB_ENT` מוגדר) |
| **Organization slug** | הזנה ידנית אם הארגון לא ברשימה |
| **Member role** | `direct_member` (ברירת מחדל), `admin`, `billing_manager`, או `reinstate_member` |

## הזמנה בודדת

1. בחרו ארגון.
2. הזינו כתובת אימייל.
3. לחצו **שלח הזמנה**.

GitHub שולח הזמנה לאימייל (גם אם אין עדיין חשבון GitHub מקושר).

## העלאת Excel מרוכזת

1. הכינו קובץ `.xlsx` (או הורידו את **תבנית Excel** מהלשונית).
2. **חובה:** בגיליון הראשון עמודה בשם `email` (או `Email` / `EMAIL` — ללא תלות ברישיות).
3. העלו את הקובץ — תוצג תצוגה מקדימה של האימיילים הייחודיים.
4. לחצו **הזמן N משתמשים**.

### דוגמת מבנה קובץ

קבצי סדנה / משתתפים יכולים לכלול עמודות נוספות (שם, תחום, IP וכו') — הן **מתעלמות**. מספיק שעמודת `email` קיימת:

| שם תחום | שם פרטי | שם משפחה | Email | כתובת IP |
|---------|---------|----------|-------|----------|
| פלטפורמות | אריאל | כהן | arielc@example.com | 172.22.47.239 |
| חווית לקוח | גל | שחר | galsha@example.com | 172.22.94.66 |

### שגיאות נפוצות

| מצב | הודעה |
|-----|--------|
| אין עמודה `email` | הקובץ חייב לכלול עמודה בשם `"email"` |
| קובץ ריק | הקובץ ריק או לא ניתן לקריאה |
| אין ערכים תקינים בעמודה | לא נמצאו כתובות אימייל / אף ערך לא תקין |
| 403 מ-GitHub | אין הרשאת בעלים / `admin:org` על הארגון שנבחר |

שורות עם אימייל לא תקין **מדולגות** (נספרות בהודעת האזהרה) — שאר הרשימה עדיין נשלחת.

## תוצאות

לאחר השליחה מוצגת טבלה לכל אימייל: הצלחה / כישלון + הודעת GitHub (למשל כבר חבר, אין מושבים פנויים).

לחצו **הורד תוצאות** כדי לייצא CSV (`email`, `status`, `http_status`, `message`, `invitation_id`, `organization`, `role`).

האפליקציה שולחת הזמנות **ברצף** עם השהייה קצרה כדי להפחית rate limiting משני של GitHub. מקסימום **200** אימיילים לבקשה.

## API

`POST /api/org-invitations` — גוף: `{ org, emails[], role? }`.

קורא ל-GitHub: `POST /orgs/{org}/invitations` עם `{ email, role }`.

ראו [נתיבי API](../reference/api-routes) ו-[נקודות קצה GitHub](../reference/github-network-endpoints).
