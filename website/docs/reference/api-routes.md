# נתיבי API (שרת)

| נתיב | תיאור |
|------|--------|
| `GET /api/metrics` | מדדי Copilot |
| `GET /api/user-metrics` | שימוש לפי משתמש + מטא-חיוב |
| `GET /api/usage-insights` | תובנות שימוש וחיוב |
| `GET /api/billing-status` | בדיקת זמינות Billing API |
| `GET /api/billing` | נתוני חיוב |
| `GET /api/teams` | צוותים |
| `GET /api/team-metrics` | מדדי צוות |
| `GET /api/github-stats` | סטטיסטיקות GitHub.com |
| `GET /api/health` | בריאות |
| `GET /api/ready` | מוכנות |
| `GET /api/live` | חיות |

פרמטרים נפוצים: `since`, `until`, `githubOrg`, `scope`.
