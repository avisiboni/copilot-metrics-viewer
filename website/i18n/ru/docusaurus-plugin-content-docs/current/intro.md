# Copilot Metrics Viewer

Этот проект предоставляет **панель мониторинга** для метрик использования GitHub Copilot на уровне организации, команды или предприятия — графики, таблицы, экспорт CSV и аналитика выставления счетов (когда API доступен).

## Для кого эта документация?

| Аудитория | Начните здесь |
|-----------|---------------|
| **Пользователи панели** | [Руководство пользователя](./user-guide/overview) |
| **Администраторы / DevOps / Разработчики** | [Обзор настройки](./setup/overview) · [Справочник](./reference/environment-variables) |

## Требования

- Аккаунт GitHub **Организация** или **Предприятие** с включёнными Copilot Metrics.
- Token или OAuth / GitHub App с правильными [разрешениями](./reference/scopes).
- Для **премиум-кредитов** и **использования и выставления счетов**: `manage_billing:copilot` и расширенное выставление счетов.
