# Copilot Metrics Viewer

Bu proje, GitHub Copilot kullanım metrikleri için organizasyon, ekip veya kurumsal düzeyde bir **gösterge paneli** sağlar — grafikler, tablolar, CSV dışa aktarma ve API kullanılabilir olduğunda faturalandırma içgörüleri.

## Bu dokümantasyon kimin için?

| Hedef kitle | Buradan başlayın |
|-------------|------------------|
| **Panel kullanıcıları** | [Kullanıcı kılavuzu](./user-guide/overview) |
| **Yöneticiler / DevOps / Geliştiriciler** | [Kurulum genel bakış](./setup/overview) · [Referans](./reference/environment-variables) |

## Gereksinimler

- Copilot Metrics etkin GitHub **Organizasyon** veya **Kurumsal** hesabı.
- Doğru [izin kapsamlarına](./reference/scopes) sahip Token veya OAuth / GitHub App.
- **Premium krediler** ve **kullanım ve faturalandırma** için: `manage_billing:copilot` ve gelişmiş faturalandırma.
