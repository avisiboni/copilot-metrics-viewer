# Copilot Metrics Viewer

本项目为 GitHub Copilot 使用情况提供**仪表盘**，支持组织、团队或企业级别的图表、表格、CSV 导出以及账单洞察（当 API 可用时）。

## 适用人群

| 用户类型 | 从这里开始 |
|----------|------------|
| **仪表盘用户** | [用户指南](./user-guide/overview) |
| **管理员 / DevOps / 开发者** | [安装概述](./setup/overview) · [参考文档](./reference/environment-variables) |

## 系统要求

- GitHub **组织**或**企业账户**，并已启用 Copilot Metrics。
- 具有正确[权限范围](./reference/scopes)的 Token 或 OAuth / GitHub App。
- **高级积分**和**使用与账单**功能需要：`manage_billing:copilot` 及增强账单。
