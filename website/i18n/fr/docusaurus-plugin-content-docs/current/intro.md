# Copilot Metrics Viewer

Ce projet fournit un **tableau de bord** pour les métriques d'utilisation de GitHub Copilot au niveau organisation, équipe ou entreprise — graphiques, tableaux, export CSV et informations de facturation quand l'API est disponible.

## Pour qui est cette documentation ?

| Public | Commencez ici |
|--------|---------------|
| **Utilisateurs du tableau de bord** | [Guide utilisateur](./user-guide/overview) |
| **Admins / DevOps / Développeurs** | [Vue d'ensemble de la configuration](./setup/overview) · [Référence](./reference/environment-variables) |

## Prérequis

- Compte GitHub **Organisation** ou **Entreprise** avec Copilot Metrics activé.
- Token ou OAuth / GitHub App avec les bonnes [autorisations](./reference/scopes).
- Pour les **crédits premium** et **l'utilisation et facturation** : `manage_billing:copilot` et facturation avancée.
