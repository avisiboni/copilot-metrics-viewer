# Copilot Metrics Viewer

Dieses Projekt bietet ein **Dashboard** für GitHub Copilot-Nutzungsmetriken auf Organisations-, Team- oder Unternehmensebene — Diagramme, Tabellen, CSV-Export und Abrechnungseinblicke (wenn die API verfügbar ist).

## Für wen ist diese Dokumentation?

| Zielgruppe | Hier starten |
|------------|--------------|
| **Dashboard-Benutzer** | [Benutzerhandbuch](./user-guide/overview) |
| **Admins / DevOps / Entwickler** | [Setup-Übersicht](./setup/overview) · [Referenz](./reference/environment-variables) |

## Voraussetzungen

- GitHub **Organisation** oder **Enterprise** mit aktivierten Copilot Metrics.
- Token oder OAuth / GitHub App mit den richtigen [Berechtigungen](./reference/scopes).
- Für **Premium-Credits** und **Nutzung & Abrechnung**: `manage_billing:copilot` und erweitertes Billing.
