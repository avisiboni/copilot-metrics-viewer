# Copilot Metrics Viewer

Proyek ini menyediakan **dasbor** untuk metrik penggunaan GitHub Copilot di tingkat organisasi, tim, atau perusahaan — grafik, tabel, ekspor CSV, dan wawasan penagihan saat API tersedia.

## Untuk siapa dokumentasi ini?

| Pengguna | Mulai di sini |
|----------|---------------|
| **Pengguna dasbor** | [Panduan pengguna](./user-guide/overview) |
| **Admin / DevOps / Pengembang** | [Ikhtisar pengaturan](./setup/overview) · [Referensi](./reference/environment-variables) |

## Persyaratan

- Akun GitHub **Organisasi** atau **Perusahaan** dengan Copilot Metrics yang diaktifkan.
- Token atau OAuth / GitHub App dengan [izin](./reference/scopes) yang benar.
- Untuk **kredit premium** dan **penggunaan & penagihan**: `manage_billing:copilot` dan penagihan yang ditingkatkan.
