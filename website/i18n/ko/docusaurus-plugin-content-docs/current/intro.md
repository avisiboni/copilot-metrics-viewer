# Copilot Metrics Viewer

이 프로젝트는 조직, 팀 또는 엔터프라이즈 수준에서 GitHub Copilot 사용 메트릭을 위한 **대시보드**를 제공합니다 — 차트, 테이블, CSV 내보내기, API 사용 가능 시 청구 인사이트.

## 이 문서는 누구를 위한 것인가요?

| 대상 | 시작 페이지 |
|------|------------|
| **대시보드 사용자** | [사용자 가이드](./user-guide/overview) |
| **관리자 / DevOps / 개발자** | [설정 개요](./setup/overview) · [레퍼런스](./reference/environment-variables) |

## 요구사항

- Copilot Metrics가 활성화된 GitHub **조직** 또는 **엔터프라이즈** 계정.
- 올바른 [권한 범위](./reference/scopes)를 가진 Token 또는 OAuth / GitHub App.
- **프리미엄 크레딧** 및 **사용량 및 청구**의 경우: `manage_billing:copilot` 및 향상된 청구 필요.
