# Copilot Metrics Viewer

Este proyecto proporciona un **panel de control** para las métricas de uso de GitHub Copilot a nivel de organización, equipo o empresa — gráficos, tablas, exportación CSV e información de facturación cuando la API está disponible.

## ¿Para quién es esta documentación?

| Audiencia | Empieza aquí |
|-----------|--------------|
| **Usuarios del panel** | [Guía de usuario](./user-guide/overview) |
| **Administradores / DevOps / Desarrolladores** | [Configuración inicial](./setup/overview) · [Referencia](./reference/environment-variables) |

## Requisitos

- Cuenta de GitHub **Organización** o **Empresa** con Copilot Metrics habilitado.
- Token u OAuth / GitHub App con los [permisos](./reference/scopes) correctos.
- Para **créditos premium** y **uso y facturación**: `manage_billing:copilot` y facturación mejorada.
