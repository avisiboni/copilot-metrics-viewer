# GitHub scopes

Recommended PAT: `copilot`, `manage_billing:copilot`, `read:org`, plus enterprise scopes when needed.

For emails: `read:user` or `admin:org` with SAML.

## Invite members

- Classic PAT: `admin:org` (token user must be an organization owner)
- Fine-grained / GitHub App: **Organization members → Write**
- See [Invite members](../user-guide/invite-members)
