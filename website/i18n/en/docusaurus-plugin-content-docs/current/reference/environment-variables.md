# Environment variables

Public: `NUXT_PUBLIC_SCOPE`, `NUXT_PUBLIC_GITHUB_ORG`, `NUXT_PUBLIC_GITHUB_ENT`, `NUXT_PUBLIC_GITHUB_TEAM`, `NUXT_PUBLIC_IS_DATA_MOCKED`, `NUXT_PUBLIC_USING_GITHUB_AUTH`, `NUXT_PUBLIC_DOCS_URL`, and branding: `NUXT_PUBLIC_BRAND_LOGO_PATH`, `NUXT_PUBLIC_BRAND_LOGO_ALT`, `NUXT_PUBLIC_BRAND_APP_NAME`, `NUXT_PUBLIC_BRAND_META_DESCRIPTION`, `NUXT_PUBLIC_BRAND_FOOTER_PROJECT_URL`, `NUXT_PUBLIC_BRAND_FAVICON_PATH` (defaults use `public/brand/logo.png`).

Server: `NUXT_GITHUB_TOKEN`, `NUXT_SESSION_PASSWORD`, OAuth client id/secret/scope, `HTTP_PROXY`, `NITRO_PORT`.
