# Environment variables

Public: `NUXT_PUBLIC_SCOPE`, `NUXT_PUBLIC_GITHUB_ORG`, `NUXT_PUBLIC_GITHUB_ENT`, `NUXT_PUBLIC_GITHUB_TEAM`, `NUXT_PUBLIC_IS_DATA_MOCKED`, `NUXT_PUBLIC_USING_GITHUB_AUTH`, `NUXT_PUBLIC_DOCS_URL`.

Server: `NUXT_GITHUB_TOKEN`, `NUXT_SESSION_PASSWORD`, OAuth client id/secret/scope, `HTTP_PROXY`, `NITRO_PORT`.
