# Organization tab

Organization- or enterprise-level Copilot metrics for the selected period.

## KPI cards

Acceptance rates, total suggestions, lines suggested/accepted, and related totals.

## Charts

Trends for acceptance, suggestions vs acceptances, lines, active users, and DAU/WAU/MAU.

See [GitHub Copilot Metrics API](https://docs.github.com/en/rest/copilot/copilot-metrics) for metric definitions.
