# Navigation and date range

## Sidebar

Tabs are listed in the side navigation. Switching tabs keeps your date range (in-memory).

## Date filter

At the top of the content area:

1. Click the date row to expand.
2. Set **From** / **To**.
3. Optional: **Exclude holidays**.
4. **Apply** reloads data.
5. **Last 28 days** resets the window.

## URLs

Share links such as `/?tab=users` or `/?tab=usage-billing`.
