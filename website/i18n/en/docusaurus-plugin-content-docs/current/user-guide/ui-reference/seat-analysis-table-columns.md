# עמודות — לשונית Seat analysis

![לשונית Seat analysis](/img/ui/seat-analysis-tab.png)

## טבלת מושבים (רשימת Seats)

מסוננת בלחיצה על כרטיסי KPI (Total / Never used / No activity 7d / 30d). **ללא** טווח תאריכים גלובלי — מצב נוכחי מ-`/api/seats`.

| # | עמודה | מפתח | הסבר |
|---|--------|------|------|
| 1 | **מס׳** | `serialNumber` | מספר סידורי בשורה (תצוגה) |
| 2 | **התחברות** | `login` | לוגין GitHub של בעל המושב |
| 3 | **מזהה GitHub** | `id` | מזהה משתמש GitHub |
| 4 | **צוות מקצה** | `team` | צוות שקיבל את המושב (אם זמין) |
| 5 | **זמן הקצאה** | `created_at` | מתי הוקצה המושב |
| 6 | **פעילות אחרונה** | `last_activity_at` | פעילות Copilot אחרונה |
| 7 | **עורך אחרון** | `last_activity_editor` | עורך IDE בפעילות האחרונה |

ראו גם: [ניתוח מושבים](../seat-analysis).

## טבלת «מושבים לפי חודש» (פירוט לחשבונית)

`BrandMonthlySeatInvoiceSection` — עמודות דינמיות:

| עמודה | מפתח | תמיד? | הסבר |
|--------|------|--------|------|
| **חודש** | `monthLabel` | כן | חודש קלנדרי |
| **מושבים חדשים** | `new_seats` | כן | הקצאות חדשות בחודש (או שינוי לעומת חודש קודם במצב היסטורי) |
| **מושבים קיימים** | `existing_seats` | כן | מושבים שכבר היו מוקצים |
| **סה״כ מושבים** | `total_seats` | כן | סה״כ מוקצים לחודש |
| **עלות קיימים** | `existing_cost_label` | אם `NUXT_PUBLIC_COPILOT_SEAT_UNIT_PRICE` &gt; 0 | עלות מושבים קיימים |
| **עלות חדשים** | `new_cost_label` | אם מחיר מושב מוגדר | עלות מושבים חדשים |
| **עלות חודש** | `monthly_cost_label` | אם מחיר מושב מוגדר | סה״כ עלות חודש |
| **תאריך צילום** | `snapshot_date` | במצב היסטורי | תאריך צילום מצב יומי |

שורת **סה״כ תקופה** בתחתית הטבלה מסכמת עמודות מספריות (ולעיתים עלות).

| מצב | חישוב |
|-----|--------|
| **Historical** | סה״כ בסוף חודש מצילומי מצב — [מצב היסטורי](../../deployment/historical-mode) |
| **Direct API** | לפי `created_at` למושבים שעדיין מוקצים |
