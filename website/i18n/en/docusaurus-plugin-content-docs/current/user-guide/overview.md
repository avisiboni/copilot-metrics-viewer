# User guide

How to use the dashboard **without** server configuration.

## Recommended workflow

1. Set a **date range** (up to 100 days) — [Navigation & dates](./navigation-and-dates).
2. Open the relevant tab.
3. Filter by user / team / day when needed.
4. Export from **API response** if you need CSV.
