# User guide

How to use the dashboard **without** server configuration.

![Dashboard overview screenshot](/img/ui/dashboard-overview.png)

## Recommended workflow

1. Choose a **date range** (up to 100 days) — [Navigation and dates](./navigation-and-dates).
2. Open the relevant tab.
3. Filter by user / team / day as needed.
4. Ask the [AI assistant](./ai-chat) about metrics.
5. Export from **API response** if you need CSV.

## Main tabs

- [Organization](./organization) — KPIs, AI adoption cohorts
- [Teams](./teams) · [Team-scoped URLs](./team-scoped-views)
- [Users](./users) — table, PRU, adoption phase, **usage patterns**
- [Usage & billing](./usage-billing) — billing, user dialog
- [Usage patterns](./usage-patterns) — heuristic labels, formulas, interpretation
- [Usage insights](./usage-insights) — models and Agent
- [Seat analysis](./seat-analysis) — seats and monthly trends
- [AI assistant](./ai-chat)
- [Export](./export)
