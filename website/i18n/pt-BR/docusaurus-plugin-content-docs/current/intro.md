# Copilot Metrics Viewer

Este projeto fornece um **painel** para métricas de uso do GitHub Copilot em nível de organização, equipe ou empresa — gráficos, tabelas, exportação CSV e insights de faturamento quando a API estiver disponível.

## Para quem é esta documentação?

| Público | Comece aqui |
|---------|-------------|
| **Usuários do painel** | [Guia do usuário](./user-guide/overview) |
| **Administradores / DevOps / Desenvolvedores** | [Visão geral da configuração](./setup/overview) · [Referência](./reference/environment-variables) |

## Requisitos

- Conta GitHub de **Organização** ou **Empresa** com Copilot Metrics habilitado.
- Token ou OAuth / GitHub App com os [escopos](./reference/scopes) corretos.
- Para **créditos premium** e **uso e faturamento**: `manage_billing:copilot` e faturamento aprimorado.
