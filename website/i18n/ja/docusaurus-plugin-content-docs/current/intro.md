# Copilot Metrics Viewer

このプロジェクトは、組織・チーム・エンタープライズレベルで GitHub Copilot の使用状況を確認できる**ダッシュボード**を提供します。グラフ、テーブル、CSV エクスポート、請求インサイト（API が利用可能な場合）に対応しています。

## 対象ユーザー

| ユーザー | 開始ページ |
|----------|------------|
| **ダッシュボードユーザー** | [ユーザーガイド](./user-guide/overview) |
| **管理者 / DevOps / 開発者** | [セットアップ概要](./setup/overview) · [リファレンス](./reference/environment-variables) |

## 必要条件

- Copilot Metrics が有効な GitHub **組織**または**エンタープライズ**アカウント。
- 正しい[スコープ](./reference/scopes)を持つ Token または OAuth / GitHub App。
- **プレミアムクレジット**と**使用状況と請求**には `manage_billing:copilot` と拡張請求が必要。
